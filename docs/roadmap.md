# PI05 双臂部署路线图

S01–S05 已建立协作、环境、上游依赖和右侧设备配置基础。S06 起以“一台 PI05、左右
两套 Pika、左右两台 Piper、两路独立 CAN”为唯一目标拓扑；单臂只作为分侧测试手段，
不再作为最终交付目标。

| 阶段 | 阶段目标 | 退出条件 | 最高计划验证 |
|---|---|---|---|
| S06 | 双臂基线纠偏 | 双侧配置、架构、接口、安全约束和路线统一；脚本测试通过 | 静态 |
| S07 | 双侧硬件与上游闭环 | 左右臂型号/固件；解决 S03 来源与许可证阻塞 | 真机 |
| S08 | 双侧只读通信 | 两路 CAN、两路 Pika 串口/定位和两臂 ROS 反馈可独立识别；不使能 | 真机 |
| S09 | 通用单臂驱动封装 | 同一 launch 通过 `side` 参数启动左右任一驱动，接口完全命名空间隔离 | 构建 |
| S10 | 通用安全过滤与状态桥 | 将参考右臂节点参数化为左右复用节点，补齐单元与回放测试 | 仿真/回放 |
| S11 | 双臂 bringup 与协调安全 | 同时启动双侧；任一侧关键故障触发双侧 hold/stop/disable 策略，无控制旁路 | 仿真/回放 |
| S12 | 左右分侧低速验收 | 先左后右完成方向、关节、限位、夹爪、超时和急停测试 | 真机 |
| S13 | 双臂低速协同验收 | 双臂小步长空载运动、共享工作区和碰撞边界通过现场验收 | 真机 |
| S14 | 双手遥操作联调 | 左右 Pika 分别映射对应机械臂，验证坐标系、会话、定位丢失和重连 | 真机 |
| S15 | 故障注入与恢复 | CAN/串口断流、节点崩溃、时间异常、单侧故障及重启恢复均符合安全状态机 | 真机 |
| S16 | 部署固化与交付 | 受控启动/停机、运维手册、验收清单、版本锁定和回滚演练完成 | 真机 |

## 执行约束

- S07–S08 不发送运动指令；S09–S11 优先在仿真或回放环境完成。
- S12 允许分侧测试，但每侧都必须有独立证据；右侧历史证据不能替代左侧验收。
- S13 前不得把双臂同时使能。共享空间、安装间距和碰撞风险必须先完成评审。
- 每个阶段只创建一个 `stage/SNN-<slug>` PR，前序 PR 合并后才能发布下一阶段。
- 任何真机结论必须包含时间、环境、步骤、关键输出和停止方式，且不得记录敏感标识。
