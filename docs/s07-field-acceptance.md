# S07 双侧硬件现场验收

本清单用于在**不使能、不发送 CAN/串口命令、不运动**的条件下补齐 S07 证据。先复制
本地记录模板：

```bash
cp config/s07-hardware.env.example config/s07-hardware.env
```

`config/s07-hardware.env` 已被 Git 忽略。只填写型号、固件版本、手册修订、额定值、
测量值和 `pass`/`yes` 结论；禁止填写序列号、资产编号、二维码内容、人员、场地、账号、
主机名、IP 或 MAC。

2026-09-11 已分侧核对左右机械臂铭牌，并由用户指定厂商知识库的“PIPER 标准版使用
资料”目录；两侧 `PIPER_MODEL` 可填写 `PIPER_STANDARD`，`MANUAL_REVISION` 可填写
`PIPER_USER_MANUAL_V2.0.0`。无需再次提交铭牌照片或设备标识。官方产品页给出的
DC 24 V 也是型号额定值。现场已确认左右各使用一台独立 DC 24 V、10 A、240 W 电源，
可分别填写 `POWER_VOLTAGE_V=24`、`POWER_CURRENT_A=10` 和
`POWER_RATED_W=240`。上述信息不代表电源保护、接地、固件、夹爪或安全项已通过。

型号级公开规格为 6 轴、1.5 kg 有效负载、4.2 kg 本体重量和 626 mm 工作半径。不得把
1.5 kg 写入 `PAYLOAD_KG`；该字段要求记录现场实际安装的工具/负载，并按手册确认重心。

## 安全前置

- 两台 Piper 保持禁用，ROS 控制节点未启动，工作区清空。
- 两人现场复核；一人执行检查，一人观察两侧设备和急停。
- CAN 终端测量前，两侧机械臂和总线均断电、隔离并确认无残余电压。
- 只使用对应实物型号的厂商手册判定通过值；本仓库不猜测电压、电流、接地或终端值。
- 任一侧身份不明确、接线异常、急停覆盖不完整或手册不匹配，立即停止并填写 `fail`，
  不得为了让脚本通过而改成 `pass`。

## 分侧检查

左右侧分别完成以下项目，不能用一侧结论替代另一侧：

1. 从铭牌或厂商维护界面读取 Piper 型号、Piper 固件和夹爪型号；只抄产品/版本字段，
   遮挡序列号、二维码和资产标签。
2. 找到与该型号一致的厂商手册，记录公开的手册版本或发布日期短标识。
3. 按手册核对电源额定电压、额定功率、电流能力、过流/短路保护和保护接地。记录额定
   值，电源型号可不记录；功率与电流必须分别来自可核对的规格，不能互相推算后冒充
   铭牌值。
4. 断电隔离后沿线核对 CAN-H、CAN-L、GND 与屏蔽/接地处理；测量 CAN-H 与 CAN-L
   间等效电阻。只在与该型号手册一致时填写 `CAN_TERMINATION_RESULT=pass`。
5. 检查底座紧固、防松、线缆应力释放、夹爪/工具质量和重心。负载按左右侧分别记录，
   未安装额外负载可填写 `0`，夹爪是否计入负载必须按手册口径统一。

## 公共安全检查

1. 确认急停为独立硬件链路，不依赖 PI05、ROS、Python 或网络，并实际覆盖左右两台臂。
2. 双臂保持禁用且不运动，在厂商手册允许的带电状态下触发急停；通过控制器的安全
   状态指示或手册规定的无运动方法确认两侧均响应。不要用“ROS 服务返回成功”代替。
3. 按手册复位急停，确认需要人工恢复且不会自动使能或恢复旧目标。
4. 复核双臂共享空间、底座间距、夹爪/工具包络和线缆牵拉风险。本阶段只做静态评审，
   不通过运动验证包络。

## 本地校验

填写完成后运行：

```bash
scripts/check_s07_hardware.sh
```

返回 0 只表示记录字段完整并且现场人员明确填写了通过结论，不会替代测量真实性、厂商
手册或安全责任人的判断。将脚本最后两行输出发给项目维护者；不要发送本地 `.env` 文件
或铭牌照片。

## 失败与停止

- 任一字段无法确认：保持空白，检查脚本应失败，S07 保持“等待真机验收”。
- 任一结果为 `fail`：停止后续阶段，修复并重新从安全前置开始检查。
- 发现设备正在运动、控制节点已启动或无法确认禁用状态：立即使用现场批准的硬件急停
  流程，不运行本清单中的任何软件命令。
