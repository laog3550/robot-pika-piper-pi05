# PI05 Git Sync

1. Review `git status` and the complete diff. Do not include credentials, local
   device configuration, build products, logs, or unrelated user changes.
2. Run the checks relevant to the edited code.
3. Stage only the reviewed paths and create one clear commit.
4. Push the current branch to `origin`.
5. Read back the local and remote commit IDs and report the branch and commit.

Do not merge, force-push, tag, release, or rewrite history unless the user asks.
